Google Colab (Colaboratory) 调研与使用指南

  • 官网: https://colab.research.google.com/
  • 运行环境: 基于云端的 Jupyter Notebook（Google Cloud 托管）
  • 核心定位: 免配置 Python 环境，提供免费 GPU/TPU 算力，支持云端硬盘联动与协同分享

1. 入门指南（小白实践篇）

Google Colab 是 Google 推出的一款在线交互式编程工具。简单来说，它就像一个**「云端版的 Python 笔记本」**——你不需要在自己电脑上安装 Python、配置环境变量或安装显卡驱动，只要打开浏览器就能直接写代码并运行，甚至还能免费使用 Google 提供的云端 GPU 显卡。

实践步骤

第一步：打开并新建笔记本

  1. 准备一个 Google 账号（Gmail），确保网络能正常访问 Google 服务。
  2. 在浏览器中打开 colab.research.google.com。
  3. 首次进入会弹出一个欢迎弹窗，点击右下角的 「新建笔记本」（New Notebook）。
  4. 页面会生成一个未命名的 .ipynb 文件（你可以点击左上角文件名重命名，例如 my_first_colab.ipynb）。

第二步：认识界面与单元格（Cell）

Colab 页面主要由一个个矩形的「单元格」拼接而成，分为两种基本类型：

  • 代码块（+ 代码）：用来编写和运行 Python 代码。
  • 文本块（+ 文本）：用来写 Markdown 说明文档、记笔记或放参考图。
  • 鼠标悬停在两个单元格之间，就会浮现 + 代码 和 + 文本 按钮，随时可以插入新块。

第三步：写下并运行第一行代码

  1. 鼠标点击默认生成的第一个代码单元格，输入以下代码： 
    message = "Hello, Google Colab!"
print(message)
  2. 运行代码（两种方法）：
    • 点击该单元格左侧的圆圈 播放按钮（▶）。
    • 使用最常用的快捷键：按 Shift + Enter（执行当前块，并自动跳转/新建下一块）。
  3. 稍等一两秒，单元格下方就会立刻输出打印内容。

第四步：执行终端命令与安装三方库

Colab 底层是一台完整的 Linux 虚拟机。在命令前加上英文感叹号 !，就能直接执行 Linux Shell 命令：

  • 安装额外的 Python 库： 
    !pip install numpy pandas matplotlib
  • 查看分配到的硬件配置： 
    !nvidia-smi

    注意：如果当前处于默认的 CPU 模式，运行该命令会报错 command not found。需完成下一步开启 GPU 后才可查询显卡。

第五步：免费开启 GPU 加速（跑 AI / 深度学习必备）

默认情况下 Colab 分配的是普通的 CPU 机器。如果你要运行 AI 模型或做大规模计算，可以免费换成 GPU：

  1. 点击顶部菜单栏的 「代码执行程序」（Runtime）-> 「更改运行时类型」（Change runtime type）。
  2. 在弹出的对话框中，将「硬件加速器」从 CPU 改为 T4 GPU（或下表中的其他加速器；高级卡通常需要付费 compute units）。
  3. 点击 「保存」。
  4. 此时右上角会重新连接（连接成功后会显示 RAM 和 磁盘 容量进度条）。再在代码块中运行 !nvidia-smi，就能看到分配到的显卡信息。

加速器对照（显存 + 计算单元）：Colab 用统一的 compute units 计费（约 $0.10 / unit）；越强的加速器，每小时扣的 units 越多。下表为社区实测快照，会随地区/时段波动，以连接后右上角实际烧点速率为准。

Colab 选项 实际硬件 显存/容量 约 units/hr 约 $/hr 200 units 大约能连
T4 GPU NVIDIA T4 ~15 GB 1.19 ~$0.12 ~168h（~7 天）
L4 GPU NVIDIA L4 ~22.5 GB 1.71 ~$0.17 ~117h（~5 天）
A100 GPU NVIDIA A100 40 / 80 GB 5.4 / 7.5 ~$0.54 / $0.75 ~37h / ~27h
G4 GPU RTX PRO 6000 Blackwell ~96 GB ~8.7 ~$0.87 ~23h
H100 GPU NVIDIA H100 ~80 GB ~18 ~$1.80 ~11h
v5e-1 TPU TPU v5e（1 chip） HBM（非 GPU） ~3.1 ~$0.31 ~64h
v6e-1 TPU TPU v6e（1 chip） HBM（非 GPU） ~3.7 ~$0.37 ~54h

心算：能用小时数 ≈ 持有 units ÷ 该加速器 units/hr；花费美元 ≈ 用掉的 units × 0.10。例如连 G4 跑 5 小时 ≈ 5 × 8.7 ≈ 43.5 units ≈ $4.4。A100 的 80GB 版本通常对应 High RAM；G4 在 nvidia-smi 里显示为 RTX PRO 6000。TPU 与 CUDA GPU 生态不同，适合 JAX / 部分 TensorFlow，不一定能直接替代 PyTorch CUDA 流程。

第六步：算力扣费机制与如何断开连接（避坑必看）

  • 扣费机制（按占用时长计费）： 只要你的 Notebook 处于 「已连接」（Connected） 状态，哪怕你什么代码都没运行、只是开着网页发呆，系统也会按照当前硬件的速率（见上表）每分每秒持续扣除计算单元点数。这是因为云端显卡和内存已经被你独占锁定。单纯关闭浏览器标签页后台依然会继续连着扣费。
  • 积分用完不会自动刷信用卡：余额归零后降回免费档限制，正在跑的付费运行时往往会被掐断；需要你手动再买 Pay As You Go，或等订阅下月赠送的 units。真正会按月自动扣卡的是 Pro / Pro+ 订阅续费（可在 payments.google.com 取消）。
  • 如何断开连接（停止扣点）：
    • 方法一：手动断开释放（推荐） 点击顶部菜单栏 「代码执行程序」（Runtime）-> 「断开连接并删除运行时」（Disconnect and delete runtime），或点击右上角 RAM/磁盘使用条旁边的下拉箭头选择断开。
    • 方法二：代码跑完自动关机 如果是晚上挂着跑长任务，可以在 Notebook 最后一个单元格加上： 
      from google.colab import runtime

runtime.unassign()
      当所有代码执行完毕后，系统会自动断开并释放实例，防止多扣整夜点数。

第七步：常用快捷键速查

快捷键 作用说明
Shift + Enter 运行当前单元格，并跳转到下一单元格
Ctrl + Enter 运行当前单元格，光标停留在原地
Ctrl + M B 在当前单元格下方插入新的代码块
Ctrl + M D 连续按两次 D 删除当前选中的单元格
Ctrl + M M 将当前代码块转换为 Markdown 文本块

2. 进阶与高级用法

当你跑通基础代码后，Colab 还提供了以下进阶能力，支持更复杂的开发与工程需求：

  1. 挂载 Google Drive 持久化存储： Colab 实例关闭后临时文件会被重置。运行 from google.colab import drive; drive.mount('/content/drive') 即可挂载个人云端硬盘，把训练数据集、持久化日志与模型权重保存在网盘中。
  2. 交互式表单控件（Form Fields）： 通过添加 #@param 注释语法（如 learning_rate = 0.01 #@param {type:"slider", min:0.001, max:0.1, step:0.001}），Notebook 界面会自动渲染出滑块、下拉选择框或颜色拾取器，无需写前端就能做交互式 Demo。
  3. GitHub 双向联动： 浏览器直接访问 colab.research.google.com/github/<用户名>/<仓库名>/blob/main/<文件>.ipynb 即可免克隆直接打开任何开源 Notebook；编辑完成后可在菜单栏选择「文件」->「在 GitHub 中保存副本」直接提交 commit。
  4. 终端与内网穿透（Remote Access & Web UI）： 可结合 ngrok 或 cloudflared 隧道，将 Colab 里运行的 Web 应用（如 Gradio、Streamlit、Stable Diffusion WebUI、ComfyUI）映射出公网链接访问；也可以通过 SSH 隧道使用本地 VS Code 远程连接 Colab 的计算节点进行编码。
  5. 算力升级与防闲置中断（Colab Pro / Compute Units）： 免费版受限单次会话时长与空闲掉线机制。升级 Colab Pro/Pro+ 可购买算力点数（Compute Units），解锁后台持久运行、高内存模式以及 A100 / L4 / V100 等高性能显卡，支撑大语言模型微调与大批量任务。
