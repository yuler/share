静态分享站 MVP 架构设计

2026-11-04 · architecture gh-pages

基于 GitHub Pages 的极简静态分享方案：无需后端、无需构建流程，通过统一的 CSS 变量系统与 AI 协作，随时将对话、想法、代码或媒体文件生成独立分享页。

设计原则

  • 全静态无构建：Push 即发布，GitHub Pages 直出，1 分钟内全球 CDN 生效。
  • HTML 即媒介：所有分享形式（文字、对话、代码、多媒体）统一归宿为单一语义化 HTML，天然支持多类型混合。
  • CSS 变量驱动主题：全站共享 assets/share.css，内置自动深浅色以及 paper、dark、terminal 等主题，支持页面级局部样式微调。
  • 端到端 AI 集成：通过全局 share skill，在任何终端或对话中只要一句话，AI 即自动在 s/YYYY-MM-DD-slug/ 目录生成并完成脱敏与部署。

隐私与发现性：首页默认不提供公开索引列表，全站页面注入 noindex，仅通过唯一链接直接触达。

目录规约

share/
├── index.html              # 根占位页（不公开索引）
├── assets/
│   ├── share.css           # 统一变量与原子组件库
│   └── share.js            # 代码高亮与剪贴板复制增强
├── templates/              # AI 生成骨架（chat / code / media / note）
└── s/                      # 各独立分享（以日期与语义命名）
    └── 2026-11-04-slug/
        └── index.html
